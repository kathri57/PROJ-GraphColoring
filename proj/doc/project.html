The Graph Coloring Problem

The Graph Coloring Problem (GCP) is a classic and well-studied problem in graph theory and computer science. Given an undirected graph G = (V, E), the goal is to assign a color to each vertex such that no two adjacent vertices share the same color, while using the smallest possible number of colors. This minimum number of colors is called the chromatic number of the graph, denoted χ(G).

More formally, a coloring is a function c: V → {1, 2, …, k} such that for every edge {u, v} ∈ E it holds that c(u) ≠ c(v). The Graph Coloring Problem asks for a coloring that uses the minimum possible value of k.

GCP is a well-known NP-hard problem: no polynomial-time algorithm is known that solves it optimally for arbitrary graphs, and none is believed to exist (unless P = NP). Despite this theoretical hardness, GCP has numerous practical applications, including:

  • scheduling (exam timetabling, course scheduling),
  • frequency assignment in wireless networks,
  • register allocation in compilers,
  • map coloring,
  • traffic signal optimization,
  • clustering and community detection in social networks.

This project

This project compares five heuristic algorithms for the Graph Coloring Problem:

  • Greedy — colors vertices in their natural order, assigning each vertex the smallest color not used by its already-colored neighbours.
  • Welsh–Powell — an improvement over Greedy that first sorts vertices in decreasing order of degree.
  • DSatur (Brélaz, 1979) — dynamically colors the vertex with the highest saturation degree (number of distinct colors among its colored neighbours) at each step.
  • RLF (Recursive Largest First; Leighton, 1979) — builds one independent set (color class) at a time, greedily maximizing its size.
  • MSISCA (Malatya Sequential Independent Set Coloring Algorithm; Yakut, 2025) — builds sequential independent sets by repeatedly selecting the vertex with minimum Malatya centrality.

Since none of these heuristics guarantees an optimal solution, the project evaluates and compares them across four groups of test graphs (see the Test sets tab) with respect to two main indicators: the number of colors used (a measure of solution quality) and the execution time (a measure of efficiency).
