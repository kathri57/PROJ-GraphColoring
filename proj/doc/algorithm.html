Algorithms

A graph coloring algorithm computes, for a given input graph, an assignment of colors (positive integers) to vertices such that no two adjacent vertices share the same color, using as few colors as possible.

InputA graph, given as a vertex count and a list of edges.
OutputAn array color[], where color[v] is the color assigned to vertex v.
Test of correctnessThe execution of an algorithm on a given graph is correct if, for every edge {u, v} in the graph, color[u] ≠ color[v] holds, and every vertex has been assigned a positive color.

Implementation

To implement a graph coloring algorithm, the author has to write a Java class that extends ProjectAbstractAlgorithm and overrides the execute(Input) method.

An example of a (greedy) graph coloring algorithm is the following:

public class Algorithm extends ProjectAbstractAlgorithm {

  @Override
  protected Output execute(Input input) {
    int n = input.n;
    List<List<Integer>> adj = buildAdjacency(n, input.edges);

    int[] color = new int[n];
    for (int v = 0; v < n; v++) {
      color[v] = smallestFree(adj, v, color);
    }

    return new Output(color);
  }

  // ... helper methods buildAdjacency(), smallestFree() ...
}

Algorithms implemented in this project

  • Greedy — O(|V| + |E|). Colors vertices in natural order; no global structural information is used.
  • Welsh–Powell — O(|V| log|V| + |E|). Greedy coloring after sorting vertices by decreasing degree.
  • DSatur — O(|V|²) (naive). At each step colors the vertex with the highest saturation degree.
  • RLF — O(|V|·(|V|+|E|)). Builds independent sets (color classes) one at a time, using a two-set bookkeeping strategy (candidates C, excluded X).
  • MSISCA — O(|V|²·Δ·k). Builds sequent independent sets using the Malatya centrality measure ψ(v) = Σ d(v)/d(u) over neighbours u of v.
