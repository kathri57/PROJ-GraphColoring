Test sets

To evaluate the algorithms across diverse graph structures, this project uses four test sets, each focusing on a different class of graphs.

TestSetA_Classic — Classic graphs

Six graphs with analytically known chromatic numbers: the Petersen graph (χ=3), cycles C9 (χ=3) and C12 (χ=2), the complete graph K6 (χ=6), the star graph S8 (χ=2), and the path P10 (χ=2). This test set is primarily used to verify the correctness of the algorithm implementations: all five algorithms are expected to reach the optimal number of colors on these simple, regular graphs.

TestSetB_Social — Social network graphs

Five well-known real-world social network datasets: the Zachary Karate Club (34 vertices, 78 edges), the Grevy's Zebra interaction network (27, 111), the Doubtful Sound Dolphin community (62, 159), the Florentine Families marriage network (15, 20), and the Davis Southern Women bipartite attendance network (32, 89). These graphs have heterogeneous, non-uniform degree distributions, which often reveals differences between algorithms that are not visible on simpler or random graphs.

TestSetC_Random — Erdős–Rényi random graphs

Twenty-four random graphs G(n, p), generated for every combination of n ∈ {100, 200, 400, 600, 800, 1000} and p ∈ {0.2, 0.4, 0.6, 0.8}, using a fixed seed for each graph (42-65), so the graphs are reproducible. This test set allows a systematic study of how algorithm performance (both number of colors and execution time) scales with graph size and edge density.

TestSetD_Benchmark — DIMACS-style benchmark graphs

Eleven structured benchmark graphs commonly used in the graph coloring literature:

  • Queen(n,n) graphs for n = 5, …, 10 — vertices correspond to squares of an n×n chessboard, with two vertices adjacent if a queen could move between them (same row, column, or diagonal). The chromatic number of Queen(n,n) is at least n; it equals n when n mod 6 is 1 or 5.
  • Mycielski graphs Myciel(k) for k = 3, …, 7 — triangle-free graphs with chromatic number k, constructed iteratively via the Mycielski construction. They demonstrate that a high chromatic number does not require large cliques or dense structure.
